# Sample images of the report

Eight random images of the test split that have a box of the truck family, for the section
"Sample images" of [the report](../report.md). Each file has four panels, one for each arm (H, D,
B, F; seed 0). White: the boxes of the dataset. Colour: the detections of the arm with a score of
0.5 or more.

**These files are dataset images, and they have the licence of the dataset.**

- **Source:** the MIO-TCD localization dataset, <https://tcd.miovision.com>. The name of a file is
  the ID of its image in the dataset.
- **Licence:** Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
  (CC BY-NC-SA 4.0), <https://creativecommons.org/licenses/by-nc-sa/4.0/>.
- **Changes:** the image is shown four times in one file, with boxes, class names and scores drawn
  on it.
- **These 8 files have the same licence,** CC BY-NC-SA 4.0. If you use them: give the source, do
  not use them for commercial purposes, and give your changes the same licence.
- **Citation of the dataset:** Z. Luo, F. Branchaud-Charron, C. Lemaire, J. Konrad, S. Li,
  A. Mishra, A. Achkar, J. Eichel and P.-M. Jodoin, "MIO-TCD: A New Benchmark Dataset for Vehicle
  Classification and Localization", IEEE Transactions on Image Processing, vol. 27, no. 10,
  pp. 5129–5141, 2018. DOI: 10.1109/TIP.2018.2848705.

All other images of the dataset are not in this repository.
